# MoonPV 项目申报书

**项目名称：** MoonPV：MoonBit 光伏设备 SunSpec 读取工具

**参赛者：** 苏天纬

**GitHub：** https://github.com/STW135-2026/moonpv

## 要解决的问题

支持 SunSpec 的光伏逆变器和电表可以通过局域网提供运行数据。接入时，开发者仍需处理 Modbus TCP 通信、设备模型地址、数值缩放和缺失值。MoonPV 将这些步骤做成 MoonBit 库，供网关和采集服务直接调用；命令行工具也能输出 JSON，方便设备联调和脚本取数。

例如，一套采集程序需要同时读取逆变器功率、电表功率和累计输入/输出电量。MoonPV 按设备公布的模型链定位数据，并区分多块电表，使用方不必重新编写协议收发、寄存器解码和错误处理。对采用已支持标准模型的设备，同一套接入代码可以复用。

## 已完成的功能

项目主要用 MoonBit 实现，网络层使用官方 `moonbitlang/async`。目前支持模型发现、三相逆变器 Model 103 和三相电表 Model 203 的三相电压、功率、频率，以及电表累计输入/输出电量；支持多实例选择、精确十进制输出、缺失值识别、请求超时和错误退出码。交付物包括可复用 API、native CLI、可执行示例和本机模拟演示。

## 意义与已有项目的关系

SunSpec 已有官方 Python 客户端等成熟实现。本项目的意义是让 MoonBit 程序直接接入这类设备，无需另起其他语言的采集服务。MoonBit 的通用 Modbus 库解决协议帧问题，MoonPV 在此类通信需求之上处理 SunSpec 模型链及光伏数据语义；并未依赖或复制这些库，也不把协议标准当作原创。与 SunSpec Explorer 等完整工具相比，本项目范围较小，侧重嵌入 MoonBit 程序的 API。具体来源及差异见[对比说明](DIFFERENTIATION.zh-CN.md)。

## 验证与边界

已提供 MoonBit 测试、真实本机 TCP 收发测试，以及与 SunSpec Alliance `pysunspec2` 的读取结果对照，涵盖多电表、缩放、缺失值、电量边界和异常响应；演示不需要真实设备。复现命令和结果见[验证记录](VALIDATION.zh-CN.md)。

当前只读、仅支持 Modbus TCP 和上述模型的选定字段，不包含控制、存储或监控界面。尚未完成实机测试，不声称兼容所有厂商设备或获得 SunSpec 认证。开发中使用 AI 辅助检索、编码和测试，按公开标准及独立参考客户端核对实现。
